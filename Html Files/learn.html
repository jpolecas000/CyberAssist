Basic Help

This is simple help for using tech. This page includes helpful applications, keyboard shortcuts, and troubleshooting tips. This page also includes how to sign in to our website, log in to our website, and how to make an appointment on our website.



Common Keyboard Shortcuts

  • [COPY TEXT] Ctrl + C (Windows) Cmd + C (macOS)
  • [PASTE TEXT] Ctrl + V (Windows) Cmd + V (macOS)
  • [SELECT TEXT] Ctrl + A (Windows) Cmd + A (macOS)
  • [BOLD/UNBOLD TEXT] Ctrl + B (Windows) Cmd + B (macOS)
  • [UNDO] Ctrl + Z (Windows) Cmd + Z (macOS)
  • [REDO] Ctrl + Y (Windows) Cmd + Shift + Z (macOS)

  • [ITALIC/UNITALIC TEXT] Ctrl + I (Windows) Cmd + I (macOS)
  • [UNDERLINE/UNUNDERLINE TEXT] Ctrl + U (Windows) Cmd + U (macOS)
  • [PASTE WITHOUT FORMATTING] Ctrl + Shift + V (Windows) Cmd + Shift + V (macOS)
  • [FIND TEXT] Ctrl + F (Windows) Cmd + F (macOS)
  • [REPLACE TEXT] Ctrl + H (Windows) Cmd + Option + F (macOS)
  • [DELETE PREVIOUS WORD] Ctrl + Backspace (Windows) Option + Delete (macOS)

  • [SAVE FILE] Ctrl + S (Windows) Cmd + S (macOS)
  • [PRINT FILE] Ctrl + P (Windows) Cmd + P (macOS)
  • [OPEN NEW WINDOW/DOC] Ctrl + N (Windows) Cmd + N (macOS)
  • [CLOSE WINDOW/APP] Alt + F4 (Windows) Cmd + Q (macOS)
  • [MINIMIZE WINDOW] Windows Key + Down Arrow (Windows) Cmd + M (macOS)
  • [SWITCH APPS] Alt + Tab (Windows) Cmd + Tab (macOS)

  • [SCREENSHOT] Windows Key + Shift + S (Windows) Cmd + Shift + 3 (macOS)
  • [SCREENSHOT AREA] Windows Key + Shift + S (Windows) Cmd + Shift + 4 (macOS)

  • [OPEN NEW TAB] Ctrl + T (Windows) Cmd + T (macOS)
  • [CLOSE CURRENT TAB] Ctrl + W (Windows) Cmd + W (macOS)
  • [REOPEN CLOSED TAB] Ctrl + Shift + T (Windows) Cmd + Shift + T (macOS)
  • [REFRESH PAGE] Ctrl + R (Windows) Cmd + R (macOS)
  • [OPEN HISTORY] Ctrl + H (Windows) Cmd + Y (macOS)

  • [LOCK SCREEN] Windows Key + L (Windows) Ctrl + Cmd + Q (macOS)
  • [TASK MANAGER/FORCE QUIT] Ctrl + Shift + Esc (Windows) Cmd + Option + Esc (macOS)
  • [EMOJI KEYBOARD] Windows Key + . (Windows) Ctrl + Cmd + Space (macOS)
